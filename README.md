# Homebrew Tap

This is the official Homebrew tap for tools maintained by [@sorokin-vladimir](https://github.com/sorokin-vladimir)

It contains Homebrew Formulae for CLI/TUI tools such as:

- [`tele`](https://github.com/sorokin-vladimir/tele) — TUI Telegram client
- [`downprint`](https://github.com/sorokin-vladimir/downprint) — Markdown to PDF with GitHub-like styling

---

## Installation

### Step 1 — trust and add the tap

Homebrew only loads formulae from third-party taps you have trusted.

```bash
brew trust --tap sorokin-vladimir/tap
brew tap sorokin-vladimir/tap
```

### Step 2 — install a tool

```bash
brew install sorokin-vladimir/tap/tele
brew install downprint
```
